# Setup Homework Repo

## Local Setup

1.  Create a directory where you will store your homework for the duration of the 
    bootcamp. It can be anywhere on your hard drive.

2.  Create a Git repository in that directory.

3.  Add a .gitignore file to the directory. You do not need any content in the file
    at this time. As the bootcamp progresses, we will add entries to this file.

4.  Stage the .gitignore file and commit it to your repository.


## Remote Setup

5.  Log in to your GitHub account and create a repository to hold your homework
    for the bootcamp. Be sure to make it a public repository so that the instructor(s)
    can access it to grade your homework.

6.  Copy the URL for cloning the repository. Back in your local Git repository, set up
    the new GitHub repository as a remote and push your main branch.

7.  Refresh the browser to verify that your empty folder shows up.

8.  Copy the URL from your browser and send it in an email to drew@logicalimagination.com 
    so that your future homework can be accessed and graded.


## Homework Going Forward

9.  When homework is required to be turned in, create a folder in your local repository
    using the date the homework was assigned as the name of the folder. Please use
    "yyyy-mm-dd" as the format so that it sorts in chronological order.

10. Place your finished homework in that folder, create a commit, and push the branch to
    the remote repository, and that will submit your homework.

11. When homework is assigned, it will be due by the beginning of the next class. Homework
    assigned on a Friday afternoon will be due by 9:00 Monday morning.

    NOTE: Once the hybrid portion of the bootcamp starts, if the next workday after
    homework assignment will be an in-office day, homework will still be due as if 
    that was an in-class day. For example, if homework is assigned on Friday afternoon,
    and you are in the office Monday and Tuesday, the homework is still due by 9:00
    Monday.
